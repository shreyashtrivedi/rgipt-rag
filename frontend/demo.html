How the chat widget is added

This page stands in for a page of the college website. The only change it needs to get the chat button (bottom right) is this one line before </body>:

<script src="https://YOUR-BOT-ADDRESS/widget.js" defer></script>

The chat opens in a popup and does not change anything else on the page. On phones it opens full screen. Answers come only from the public website content, with links to the sources.
